About the timings: each number is a single measurement taken by the C++ server on a very small graph. At this scale the times are tiny and noisy (they change from run to run and depend on caching and CPU scheduling), so they should not be read as a universal ranking of the two algorithms. A* is not always faster than Dijkstra; on this graph it may explore fewer, the same number of, or even more nodes depending on the route.

All routes are calculated by the C++ backend (POST /api/route); this page only sends requests and draws the answers.
